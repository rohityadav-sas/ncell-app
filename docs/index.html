Installation

Requires Node.js 22.12 or newer. Works on Windows, macOS and Linux.

Install the CLI

Install the command globally.

npm install -g ncell

Show the available commands.

ncell --help

Run without installing globally

npx ncell --help

Install the package

npm install ncell

See Use as a package for TypeScript and JavaScript examples.

Credential storage

The CLI uses your native OS credential store. On Linux, unlock a Secret Service provider such as GNOME Keyring or KWallet with Secret Service enabled. A desktop session normally provides its D-Bus connection.

For a headless Node.js application, provide an in-memory or custom session store. This package currently targets Node.js.

Interactive mode

Open an interactive command prompt with autocomplete.

ncell
Key Action
Ctrl+Space Show suggestions
Up / Down Select a suggestion, or browse command history
Tab / Enter Accept the selected suggestion
Esc Dismiss suggestions
Ctrl+C / exit Close interactive mode

Authentication

Sign in with an OTP:

ncell login 98XXXXXXXX

Resume instead of resending OTP again

ncell login 98XXXXXXXX --verify

Use this after an interruption or mistyped OTP. It resumes the pending login for that number without generating another OTP.

Multiple accounts

Log in to save an account and switch to it. Use the commands below to manage saved accounts.

Add an account

Save another account without changing the active account.

ncell account add 98XXXXXXXX

List accounts

Show all saved accounts and which one is active.

ncell account list

Switch accounts

Switch to a saved account without requesting another OTP.

ncell account switch 98XXXXXXXX

Remove an account

Remove the specified saved account. If it is active, another saved account becomes active when available. 

ncell account remove 98XXXXXXXX

Inspect or remove the saved session

Session status

Show the active account, login time and saved token expiry. This reads the saved session without checking token acceptance with Ncell. 

ncell status

Log out

Remove only the active account. Another saved account becomes active if available.

ncell logout

Sessions and token refresh

Tokens and device identity are stored in your OS's native credential store. Accounts stay separate from the Rust CLI.

The credential service keeps its original name, ncell-app, so existing npm logins survive the package rename. Each account has its own secure entry. The CLI never stores tokens in scripts or plain-text configuration files.

Automatic refresh

The CLI refreshes tokens when Ncell reports an expired access token. A rejected refresh token requires a new login. Other failures do not trigger reward-request retries.

Manual refresh

ncell refresh

Balance and profile

Check your balance

Show your current balance, data, voice and SMS allowances.

ncell balance

View your profile

Show the account number, name, SIM type, status, plan and payment mode.

ncell profile

Plans and categories

Browse plans

List plans in the default category 66.

ncell plans

List categories

Find the available category IDs.

ncell plans categories
Category Type
50 SMS
61 Voice
66 Data & Voice (default)

View a specific category

List plans in category 61 (Voice). Use the category ID from the category list from ncell plans categories. 

ncell plans --category 61

Search and sorting

Search within a category

Search for SMS plans in category 50.

ncell plans search "SMS" --category 50

Search and sort by price

Find matching plans, ordered by price from low to high.

ncell plans search "Super" --sort price

Search and sort by validity

Find matching plans, ordered by longest validity first, then lowest price.

ncell plans search "Combo" --sort validity:desc,price:asc

Sort by more than one field

Combine sort fields

Separate ordered sort fields with commas.

ncell plans search "SMS" --category 50 --sort validity:desc,price:asc

Supported fields are price and validity. Directions are asc and desc; default is asc.

Subscribe to a plan

Find a plan

List plans in the category and note the plan ID you want.

ncell plans --category 50

Subscribe

Use the plan ID and its category. Paid packs deducts money from your balance, so the command shows the name and price and asks for confirmation. Use --yes to skip it (usually, used in scripts). 

ncell plans subscribe 984 --category 50

The plan ID is a required positional argument. Use a category ID from the category list; --category defaults to 66.

Send Free SMS

ncell sms send-free 98XXXXXXXX "Hello"

Game rewards

Check in daily, claim task rewards, view your rankings, or play games.

Daily check-in

Claims today's check-in reward and displays your streak, weekly points and token balance. 

ncell game check-in

Task status

Lists task IDs, progress, rewards and status.

ncell game status

Claim task rewards

Use task IDs from ncell game status.

ncell game claim-task 1,2,3

Claim every completed task.

ncell game claim-task all

Scratch card

Play a scratch card using your game tokens.

ncell game scratch
Scratch 1 completed. Reward awarded: 50. Game tokens: 160. Weekly points: 6695.

Spinner

Spin using your game tokens.

ncell game spin
Spin 1 completed. Reward awarded: 50. Game tokens: 160. Weekly points: 6695.

Rankings

Shows your weekly performance, last week's result, prizes and leaderboard.

ncell game ranks

Play multiple games

Multiple spins

Play three spins with a 1.5-second delay between games.

ncell game spin --count 3 --delay 1.5s

Multiple scratch cards

Play three scratch cards with a one-minute delay between games.

ncell game scratch --count 3 --delay 1m

Multiple math games

Play two math games with a 1.5-hour delay between games.

ncell game math --count 2 --delay 1.5h
  • --count is number of games (default 1).
  • --delay is the amount of waiting time between each game (defaults is 0)

Use remaining tokens

Use --count all to use all tokens to play the game until you run out of tokens. 

ncell game spin --count all --delay 1.5s

Scripts

Create a reusable script for running multiple commands at once.

Create a script

Use a name ending in .ncell.

ncell script create daily.ncell

List scripts

List scripts saved in the CLI, sorted by name.

ncell script list

Edit a script

Opens a saved script in your default text editor.

ncell script edit daily.ncell

Delete a script

Delete a script using its name. This does not affect files in the current folder.

ncell script delete daily.ncell

Run a script

Edit and save the file, then run it by name. The CLI checks saved scripts first, then the current folder. 

ncell script run daily.ncell

File format

Write command per line. The ncell prefix is optional. Blank lines and lines starting with # are ignored. Use single or double quotes around arguments containing spaces. 

sms send-free 98XXXXXXXX "Hello from my script"

Script example

# Daily rewards
ncell game check-in
ncell game claim-task 1,2,3,4,5,6,7,8

# Spinner reward
ncell game spin --count 5
ncell game claim-task 22

# Scratch card reward
ncell game scratch --count 4
ncell game claim-task 23

# Math reward
ncell game math --count 1
ncell game claim-task 26

# Game Warrior reward
ncell game claim-task 18

# Math Genius reward
ncell game math --count 4
ncell game claim-task 24

# Spend remaining tokens
ncell game spin --count all

# Final checks
ncell game status
ncell game ranks

Use as a package

import ncell from 'ncell';

// Request an OTP, then enter the code sent to your phone.
await ncell.requestOtp('98XXXXXXXX');
await ncell.verifyOtp('98XXXXXXXX', '123456');

console.log(await ncell.balance());
console.log(await ncell.checkIn());

Use a named factory when you need separate instances or options:

import { createNcellApp, NcellError } from 'ncell';

const app = createNcellApp({ timeoutMs: 90_000 });

try {
  const result = await app.spin({
    count: 3,
    delay: '1.5s',
    onEvent: (event) => console.log(event),
  });
  console.log(result.games, result.stop);
} catch (error) {
  if (error instanceof NcellError) {
    console.error(error.code, error.status, error.message);
  } else {
    throw error;
  }
}

SDK methods do not prompt or print. Provide manualAnswer when automatic math may need help: 

await app.math({
  count: 1,
  manualAnswer: async (question) => {
    return getAnswerFromYourInterface(question);
  },
  onEvent: (event) => {
    if (event.event === 'answer') showAnswerInYourInterface(event.result);
  },
});

getAnswerFromYourInterface and showAnswerInYourInterface represent your own UI functions. Without a handler, unsupported math rejects with MANUAL_ANSWER_REQUIRED and the question in error.response.

In-memory and custom stores

import { createNcellApp, MemorySessionStore } from 'ncell';

const app = createNcellApp({ store: new MemorySessionStore() });

An in-memory store lasts only as long as the process. Log in through requestOtp and verifyOtp, or initialize the store with a typed Session obtained through your own secure storage.

You can implement the exported SessionStore interface with load(), save(session) and clear(). Optional withLock(operation) lets a store protect transactions across instances or processes.

Embed the CLI or script tools

import { runCli } from 'ncell/cli';
import { createNcellApp, MemorySessionStore } from 'ncell';

await runCli(['game', 'status'], {
  app: createNcellApp({ store: new MemorySessionStore() }),
});
